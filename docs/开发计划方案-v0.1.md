> 赛事：第九届传智杯 · AI Web 网页开发挑战赛（大学B组，团队赛）

## 1. 项目定位

**一句话**：一座让人隔着屏幕就想动身的广西——3D 地图漫游四城九景，AI 替风景开口说话。

**核心体验**：广西 3D 浮雕地图 → 点击四色城市光柱（百色红/南宁绿/北海蓝/桂林青）→ 下钻城市地图 → 点击景点 → 沉浸式景点卡片（实拍素材 + AI 图生视频"唤醒风景" + AI 讲解员语音解说）。

### 1.1 竞赛评分映射（策略锚点）

| 评分维度 | 权重 | 我们的应对 |
|---------|------|-----------|
| AI 技术深度 | 35% | 四层 AI：多模态识景 + RAG 知识问答 + AIGC 图生视频 + TTS 语音讲解 |
| 创新性 | 25% | 3D 地图下钻交互 + "唤醒风景"（静照变活视频）+ 城市欢迎语音彩蛋 |
| 前端工程质量 | 10% | Vue3 组件化 + 数据驱动内容 + Git 规范提交历史 |
| 实用性 | 10% | 真实景点、真实素材、可当出行种草工具 |
| 用户体验 | 10% | 镜头感动效体系 + 声音设计 + 断网可演示 |
| 社会价值与商业潜力 | 10% | 广西文旅数字化推广，可扩展为景区/文旅局服务 |

## 2. 内容基线（四城九景）

| 城市（颜色） | 深挖景点 | 美食推荐位 |
|-------------|---------|-----------|
| 百色（红） | 百色起义纪念馆、通灵大峡谷、靖西鹅泉 | 芒果、凌云白毫茶 |
| 南宁（绿） | 青秀山、园博园 | 老友粉、酸嘢 |
| 北海（蓝） | 银滩、冠头岭 | 海鲜、侨港糖水 |
| 桂林（青） | 漓江、象鼻山 | 桂林米粉、罗汉果 |

**内容四重叙事模型**（每个景点的故事素材按此结构入库）：
① 地理科普（地貌成因）② 民间传说 ③ 历史人事 ④ 风物延伸（最佳季节/交通/周边美食）

## 3. 可调整架构（本方案的核心设计）

> 原则：**内容、展示、AI 服务、功能开关四层解耦**——改任何一层不动其他层。

### 3.1 分层结构

```
┌─ 配置层 config/ ── 功能开关（一键启停功能，不动代码）
│    feature.flags.js: { map3D: true, voiceWelcome: true, awakenVideo: true, ... }
│
├─ 内容层 content/ ── 全部内容数据化，改景点=改JSON，零代码改动
│    ├─ cities.json            四城坐标/颜色/欢迎语
│    ├─ attractions/{id}.json  九景详情（叙事四层结构+素材清单）
│    ├─ foods.json             美食推荐位
│    └─ assets/                图片/视频/音频，按景点ID归档
│
├─ 展示层 frontend/ (Vue3 + Vite + Pinia + Element Plus)
│    ├─ MapStage    地图舞台组件：3D(ECharts GL) 与 2D(SVG) 双实现，同份数据源，可切换
│    ├─ CityLayer   城市下钻层
│    ├─ AttractionCard 景点卡片（大图/Ken Burns/唤醒视频按钮/AI讲解）
│    └─ Narrator    AI讲解员（TTS+字幕同步）
│
└─ 服务层 backend/ (Spring Boot)
     ├─ LLMAdapter    多模态大模型适配器（可换：智谱/通义/火山…）
     ├─ RAGService    知识库检索问答（向量库+九景知识库）
     ├─ TTSAdapter    语音合成适配器（可换供应商）
     └─ MediaService  素材静态服务
```

### 3.2 "可调整"的四个保障机制

1. **数据驱动内容**：景点增删改只动 `content/*.json`。将来加柳州螺蛳粉、加第五座城，不改一行组件代码。
2. **适配器模式**：AI 供应商全部收口在 Adapter 接口后。某家 API 涨价/停服，换实现类即可。
3. **功能开关**：`feature.flags.js` 一眼全站功能清单。唤醒视频做不完？`awakenVideo: false`，作品照样完整提交。
4. **双地图降级**：3D 地图与 2D SVG 地图共用同份坐标数据。答辩教室无 WebGL 时一键切 2D，演示永不翻车。

## 4. 分阶段开发计划

> 每期结束都是"完整可演示"状态——任何时候被通知提前提交，都能交。

### P0 地基（第 1-2 周）
- [ ] 建仓 + Git 规范（feat/fix/docs 前缀）+ README 骨架 + .env.example（密钥严禁入库）
- [ ] Vue3 / Spring Boot 骨架 + content 数据 Schema 设计
- [ ] 广西 GeoJSON 数据本地化（阿里 DataV 下载）+ 四城经纬度坐标核定
- [ ] 3D 地图原型：浮雕效果 + 四色光柱 + hover/点击事件打通
- **验收**：浏览器里能旋转、能点击四色光柱弹出城市名

### P1 骨肉（第 3-5 周）
- [ ] 城市下钻转场动画 + 城市地图 + 九景标记
- [ ] 景点卡片：大图轮播 + Ken Burns + 文字说明
- [ ] 城市欢迎语音（只播一次逻辑 + 浏览器音频解锁入口按钮）
- [ ] 百色三景真实素材实采（照片/视频）并入库，其余三城素材先行用占位
- **验收**：全流程可点通：地图→城市→景点→卡片，断网流畅

### P2 智能（第 6-8 周）
- [ ] RAG 知识库：九景内容入库 + 向量检索 + 问答接口
- [ ] AI 讲解员：TTS 语音 + 字幕逐句同步 + 讲解卡生成（流式）
- [ ] "唤醒风景"：AI 图生视频素材生成（即梦/可灵）+ 懒加载集成 + 失败回退
- [ ] 景点知识问答入口（限定知识域）
- **验收**：三分钟演示脚本全流程丝滑，AI 四层能力全部可见

### P3 打磨（第 9-10 周）
- [ ] 性能：首屏 <2s、图片 webp+懒加载、视频点击加载
- [ ] 2D 降级地图 + 移动端适配
- [ ] 演示视频拍摄（3 分钟）+ README 四件套补全 + 提交物打包
- **验收**：对照比赛提交物清单逐项打勾

## 6. 变更管理规则（"方案不完美"的解法）

**可以随便改（低成本区）**：
- 景点/美食内容、素材替换、文案 → 只改 JSON 和 assets
- 视觉风格（配色/字体/动效细节）→ 只改样式层
- AI 供应商 → 只换 Adapter 实现
- 增删功能 → 开关控制，不删代码

**改前须评估（中成本区）**：
- 新增页面/大交互 → 独立新组件，评估是否进演示主线
- 数据 Schema 加字段 → 向后兼容（新增可选字段，不删旧字段）

**冻结（改=伤筋动骨，除非推倒重来）**：
- 四城九景的总体结构、两级地图下钻的交互主线
- 分层架构边界（内容/展示/服务/配置）
- Git 提交规范与仓库结构

## 7. 风险与预案

| 风险 | 概率 | 预案 |
|------|------|------|
| 答辩机器无 WebGL | 低 | 2D SVG 地图一键降级 |
