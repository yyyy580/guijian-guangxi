## 1. 系统总览

《桂见广西》是一个 3D 地图漫游 + AI 深度讲解的广西文旅 Web 应用，采用**前后端分离 + 内容数据层**三段式架构：

```
┌─────────────────────────┐   SSE/HTTP    ┌──────────────────────┐
│  frontend (Vue3 + Vite)  │ ────────────▶ │  backend (Spring Boot)│
│  Three.js 3D 渲染层      │   流式 JSON    │  AI 适配器 + RAG 服务  │
└────────────┬────────────┘               └──────────┬───────────┘
             │ fetch 静态 JSON                        │ HTTPS
             ▼                                       ▼
┌─────────────────────────┐               ┌──────────────────────┐
│  content (内容数据层)     │               │  智谱开放平台 GLM 系列  │
│  城市/景点/GeoJSON/媒体   │               │  chat / embedding /   │
│  全部 JSON 数据驱动       │               │  glm-4v / tts         │
└─────────────────────────┘               └──────────────────────┘
```

- **frontend**：Vue 3 + Vite + Pinia + Element Plus + Three.js + GSAP，负责三级下钻视图、3D 渲染、流式 UI 与语音
- **backend**：Spring Boot 3 + Java 虚拟线程，负责 LLM/Embedding/TTS 统一适配、RAG 检索、SSE 推流
- **content**：城市、景点、美食、区县 GeoJSON 全部 JSON 化，静态资源（实拍图/视频）按景点 ID 组织——**改内容零代码，后端启动自动重建 RAG 索引**

## 2. 前端架构

### 2.1 三级整页下钻

视图流转由 Pinia 集中管理，`<Transition mode="out-in">` 保证每级切换为整页镜头感转场：

```
广西省图（14 市浮雕） → 城市地图（区县凸台 + 景点光柱） → 景点详情（全屏背景墙）
        ▲ selectCity                    ▲ openAttraction
        └────────────── backToProvince ─┘
```

- **省图**（`ThreeMapStage.vue` + `useGuangxiMap3d.js`）：14 市 GeoJSON 经 d3-geo 墨卡托投影后 `ExtrudeGeometry` 挤出为浮雕，四城高台拔起 + 主题色光柱（百色红/南宁绿/北海蓝/桂林青）；开场「开卷」动画由 GSAP 多段 tween 编排，逐城拔起、逐城染色；应用层常驻 tween 驱动自转，用户拖拽即暂停、静置 4 秒恢复
- **城市地图**（`CityMap.vue` + `useCityMap3d.js`）：区县级 GeoJSON 挤出台地，侧壁使用 ShaderMaterial 做城市色发光渐变；景点以细光柱 + 顶端辉光 + CSS2D 名牌标注，Three.js Raycaster 实现点击下钻与 hover 提示
- **景点详情**（`AttractionView.vue`）：实拍照片 fixed 全屏背景墙 + Ken Burns 缓放，唤醒后整页无缝切换 AI 视频

### 2.2 3D 渲染关键实现

| 问题 | 方案 |
|---|---|
| GeoJSON 绕向不一致 | `normalizeRingWinding` 逐要素计算球面面积，超过半球自动反转全部环（自愈式，不挑数据源） |
| 侧壁发光 | ExtrudeGeometry 分组材质：顶面 Phong（地形纹理）+ 侧壁 ShaderMaterial（底部城市色→顶部冰蓝渐变，按深度插值） |
| 倒影 | 克隆地图根组 `scale.z = -1` 镜像，仅保留地形网格并换成低透明度 BasicMaterial |
| 标注 | CSS2DRenderer 渲染 HTML 标签层，pointer-events 穿透不挡拖拽 |
| 拾取 | Raycaster 命中光柱/拾取球 → 回调 Vue 层（`onDrill` / `onPick`），3D 与业务彻底解耦 |
| 后期 | EffectComposer + UnrealBloomPass（strength 0.55 / threshold 0.3，只让光柱与描边进辉光） |
| 资源释放 | 所有 geometry/material/texture 登记至 Set，组件卸载全量 dispose，防内存泄漏 |

### 2.3 流式 UI 与语音

- SSE 流式渲染采用**双缓冲**：字幕缓冲只增不减（防闪烁），朗读缓冲逐句消耗（防跳句）
- 讲解员语音双兜底：优先请求后端 TTS（glm-tts 合成整段 wav），任何失败自动回退浏览器 `speechSynthesis`，保证永不哑火
- 悬停城市光柱触发欢迎语音「XX 欢迎您」，AudioContext 首次点击解锁 + 标志位防重播

### 2.4 工程化机制

- **feature.flags**：不稳定功能一键隐藏（`awakenVideo` / `ragChat` / `ttsNarrator` 等），任意组合开关下作品均完整可演示
- **dev 探针**：开发模式暴露 `window.__store`（Pinia 实例）与 `window.__gxDebug` / `__cityDebug`（场景/相机/投影函数），生产构建自动剔除，支撑无头 E2E 测试
- **降级链**：AI 图视频加载失败 → 回退静照；实拍图缺失 → 回退 CSS 艺术图；后端不可用 → 前端界面照常渲染

## 3. 后端架构（AI 能力层）

### 3.1 AI 适配器模式

`LlmProvider` 接口统一抽象 chat / embedding / vision / tts 四类能力，提供两个实现：

- `StubLlmAdapter`：演示模式（默认），无 Key 全链路可跑，伪流式输出
- `ZhipuLlmAdapter`：生产实现，对接智谱 GLM 系列

通过环境变量切换（`LLM_PROVIDER=stub|zhipu`），供应商可整体替换，业务代码零改动。

### 3.2 RAG 知识问答

```
content/*.json ──启动时──▶ 自动分块 ──▶ embedding-3 向量化 ──▶ 内存向量索引
                                                              │
用户提问 ──▶ 问题向量化 ──▶ 余弦相似检索 ──▶ 当前景点 ×1.4 加权 ──▶ 拼接上下文 Prompt
                              │
                              └─ 向量服务不可用时 ──▶ 中文 bigram 关键词兜底检索
                                        │
                                        ▼
                          glm-4-flash 流式生成 ──▶ SSE 推送 sources/delta/done
```

- 检索结果随首帧以 `sources` 事件推送，前端渲染**参考来源标签**——答案可溯源、可验证，拒绝大模型编造
- 向量索引失败启用 5 分钟退避重试，不阻塞主服务
- 前后端 SSE 统一 JSON 消息协议：`{type: sources|delta|done|error, ...}`，异常翻译为可定位中文提示（如 401 → 「Key 错误或未实名」）

### 3.3 多模态识景

`/api/vision` 接收图片，转发 glm-4v 视觉模型，返回景点识别与旅行建议；讲解词口播走 `/api/tts`（glm-tts，wav 音频流）。

### 3.4 端口与部署

后端 8080，前端 5173；Windows 提供交互式一键启动脚本（`启动后端.bat`：自动处理编码/换行兼容，引导粘贴 Key，日志落盘 `backend-start.log`）；`.env.example` 提供环境变量模板，真实密钥仅经环境变量注入，**严禁入库**。

## 4. 内容数据层

```
content/
├─ cities.json        四城元数据（颜色/口号/景点 ID 列表）
├─ attractions.json   九景四重叙事（地理/传说/历史/风物）+ 资产挂接
├─ foods.json         城市美食轻量卡片
├─ geo/               广西省 + 四城区县 GeoJSON
└─ assets/attractions/<id>.jpg|.mp4   实拍图与 AI 生成视频
```

- 前端 fetch 静态 JSON 渲染，后端读取同一份 JSON 构建 RAG 索引——**前后端共享单一事实源**
- 资产按景点 ID 命名约定挂接（`assets.cover` / `assets.awakenVideo`），新增景点只需加 JSON 与媒体文件

## 5. AI 能力与模型清单

| 能力 | 模型 | 交互链路 |
|---|---|---|
| RAG 问答 | glm-4-flash + embedding-3 | SSE 流式，附参考来源 |
| AI 讲解员 | glm-4-flash + glm-tts | 字幕流式 + 语音合成，双兜底 |
| 多模态识景 | glm-4v | 图片上传 → 识别 + 建议 |
| 唤醒风景 | 即梦 / 可灵（图生视频，预生成） | 点击懒加载，无缝切换，失败回退 |

其中 GLM-4-Flash / GLM-4V-Flash 为免费档，embedding-3 新用户有赠送额度，演示成本约等于零。

## 6. 质量保障

- **无头 E2E**：playwright-core + 系统 Chrome 驱动，覆盖三级下钻全流程、光柱真点击、SSE 流式、视频就绪态、路由往返 dispose，零 pageError 准出
- **3D 专项**：射线拾取用页面内投影坐标构造真点击验证；截图目检作为视觉准出项（渲染通过 ≠ 观感合格）
- **敏感信息扫描**：密钥三种形态全文检索，确认零泄露；`.gitignore` 排除 `.env`、日志与构建产物
